# 🤖 Florbot v1.0

A lightweight animated desktop companion for Windows built with Python and PySide6.

---

## ✨ Features

- Animated desktop companion
- Floating & expressive emotions
- Quick launcher
- Google Search
- Theme customization
- Wake & Sleep animations
- Multi-monitor support

---

## 🖥️ Requirements

Operating System
- Windows 10 / Windows 11

Required Software
- Python 3.12 or newer
- Git (optional)

Required Python Packages

pip install PySide6 keyboard pywin32

(Include every dependency from requirements.txt.)

---

## 📥 Installation

1. Download the latest Florbot release.
2. Extract the ZIP file.
3. Install Python if it is not already installed.
4. Open Command Prompt inside the Florbot folder.
5. Install the required packages:

pip install -r requirements.txt

6. Run:

python Florbot1.0.py

---

## 🚀 Auto Start (Optional)

Press Win + R

Type:

shell:startup

Create a shortcut to Florbot1.0.py (or your launcher).

Florbot will start automatically when Windows starts.

---

## ⚠️ Notes

Some launcher buttons (Chrome, VS Code, Illustrator, etc.) work only if those applications are installed in their expected locations.

If an application is not installed, its shortcut will simply not open.
