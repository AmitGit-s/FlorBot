# Florbot

Florbot is a lightweight Windows desktop companion built with Python and PySide6.

## Features
- Floating desktop mascot
- Wake and sleep lifecycle
- Blue launcher HUD
- Red Florbot HUD
- Radial theme picker
- Google Search
- Multi-monitor support
- Border-aware movement

## Installation
1. Download the release ZIP.
2. Extract it to any folder.
3. Keep the `Asset/` folder beside `Florbot1.0.py`.
4. Run `Florbot1.0.py` with Python 3 and PySide6 installed.

## Run
```bash
python Florbot1.0.py
```

## Notes
- On Windows, you can place a shortcut in the Startup folder for autostart.
- The app expects the resource folders and PNG files to remain unchanged.
